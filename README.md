# Luna Let's Go

AI-powered travel planning platform. Plan personalised trips with Luna, your AI travel assistant.

**Production:** [lunaletsgo.com](https://lunaletsgo.com)

---

## Tech Stack

- Next.js 16.1.6 (App Router, Turbopack)
- TypeScript
- Supabase (auth + database, `@supabase/ssr`)
- Anthropic Claude API (Luna chat + itinerary generation)
- Vercel (deployment)
- next-intl (EN, PT-BR, ES)

---

## Local Development

### Prerequisites

- Node.js 24.x
- A Supabase project
- Anthropic API key
- Unsplash and Pexels API keys

### Setup

```bash
npm install
cp .env.example .env.local
# Fill in your environment variables in .env.local
npm run dev
```

### Environment Variables

See `.env.example` for the full list of required variables.

## Project Structure

```
app/[locale]/      - All user-facing pages (home, plan, quiz, blog, etc.)
app/api/           - Server-side API routes (Luna chat, generate, photos, etc.)
app/auth/          - Authentication pages and OAuth callback
lib/               - Shared utilities (AI helpers, Supabase clients)
messages/          - i18n translation files (en.json, pt-BR.json, es.json)
public/            - Static assets including quiz persona images
scripts/           - Automation scripts (context update, etc.)
docs/              - Project documentation and specs
```

---

## Key Rules

- Middleware file is `proxy.ts` (NOT `middleware.ts`) - required for Next.js 16.
- Do not deploy directly from Claude Code. Push to `main` to trigger Vercel auto-deploy.
- `CLAUDE.md` is auto-regenerated by `scripts/update-context.sh`. Do not edit it manually.
- Any permanent rules belong in `CONVENTIONS.md`, not `CLAUDE.md`.
